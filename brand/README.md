# Quick Hollow Studio logo

- `logo-black.svg`: black ink, transparent background (for light backgrounds, print)
- `logo-on-black.svg`: white ink on a black square
- `logo-white.svg`: white ink, transparent background
- `logo-cream.svg`: bone-cream ink (#f6e2c4), transparent background (the website)

More versions (icon-only reaper, horizontal lockup, favicon) to come.

## Usage
One logo per placement. Use the full logo (`logo-cream.svg` on dark, `logo-black.svg` on light) when the studio is the main subject and there is room for it: the studio home page, studio splash screens, merch. Use the simplified wordmark when the studio is secondary or small: the corner of a game's page, game credits, favicons, avatars, watermarks.

## Simplified wordmark
- `wordmark-cream.svg` / `wordmark-black.svg` / `wordmark-red.svg`: stacked QUICK HOLLOW, transparent background
- `icon.svg`: cream wordmark on a black rounded square (browser icon)
- `png/avatar-1080.png`: social profile picture; `png/icon-1024.png`; PNG copies of each wordmark
Inks: bone cream #f6e2c4, near-black #100a0b, vermilion #e8321e.
